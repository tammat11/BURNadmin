# Сайт BURN Club

Статический сайт закрытого сообщества предпринимателей BURN (Алматы).

## Что внутри

- `index.html` — главная: о клубе, форматы мероприятий, города, приложение, заявка.
- `code.html` — Кодекс резидента, 12 разделов. С ним соглашается кандидат при заявке.
- `privacy.html`, `support.html` — страницы, на которые ссылается приложение в App Store.
- `styles.css`, `app.js` — оформление и логика. Без сборки и зависимостей.

## Заявки

Форма на главной пишет заявку в тот же проект Firebase (`burn-b365c`), что и
приложение, — в коллекцию `applications`. Поэтому совет клуба видит заявки с
сайта и из приложения одним списком, в админке.

Правила Firestore требуют все три согласия (Кодекс, звонок менеджера,
обработка данных), поэтому форма не даёт отправить без них: без согласий
запись просто не создастся.

Ключ Firebase в `app.js` публичный по устройству Firebase — доступ
ограничивают правила базы, а не секретность ключа.

## Запуск и публикация

Сборка не нужна. Локально:

```bash
python3 -m http.server 4000
```

Публикация на Vercel: подключить репозиторий, framework preset — **Other**,
build command оставить пустым, output directory — корень. Всё остальное
Vercel определит сам.
